# Template sheet link

The maintainer publishes the template tracker sheet (with the collector
script bound to it) and puts its copy link here. Users click it to make
their own copy.

Template copy link: not published yet

When published, replace the line above with the link in this form:

    Template copy link: https://docs.google.com/spreadsheets/d/<TEMPLATE_ID>/copy

The template must be shared as "Anyone with the link can view" so the copy
link works, and it must contain no personal data: empty Leads,
Applications, Run Log and Seen tabs, and no profile folder ID in Config.
