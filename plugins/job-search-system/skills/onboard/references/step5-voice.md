# Step 5: Voice

So drafts sound like the user, not like a template.

1. Ask for two or three things they wrote themselves and were happy with:
   an email, a post, a cover letter, a message to a colleague. Real writing
   beats polished writing. Ask them to remove anything private first.
2. Read the samples and draft:
   - **Traits**: five to eight short statements about how they write
     (sentence length, how they open, "I" or "we", formality, humor, how
     they handle numbers).
   - **Spelling and format**: spelling variety, resume date format, resume
     length, cover letter length. Ask for anything the samples do not show.
     Ask how they like to close a letter (a plain offer to help, a request
     to talk, something else), because the drafter follows it
     (`shared/cover-letter.md`). Suggest "about 300 to 350 words, one page"
     for cover letter length, and use their number if they have one.
   - **Banned phrases**: start from the template's list. Add phrases that
     are common in applications and absent from their writing, and remove
     any the user actually uses. Ask them about words or punctuation they
     dislike in other people's writing; those go here too. An entry made
     only of punctuation (for example a long dash) is matched as that
     character.
   - **Preferred wording**: what to use instead of a few of the banned
     phrases, in their words.
3. Show the drafted sections and let the user edit them.
4. Save `voice.md` with the samples under "Writing samples".

Tell the user the list will improve over time: after each application, the
system compares their final version with the draft and proposes changes
here for them to approve.
